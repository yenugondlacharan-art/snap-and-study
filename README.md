# Snap & Study

Snap & Study is an AI-powered study assistant that converts study images into simple and easy-to-understand learning content.

## Features

- 📸 Upload a study image
- 🔍 Extract text using OCR
- 🤖 AI-powered topic identification and explanation
- 📚 Step-by-step explanations
- 💡 Simple examples
- 🌍 Real-world examples
- 📝 Important terms and meanings
- ⚡ Quick revision points
- 🧠 5-question MCQ quiz
- 📊 Interactive quiz score

## Technologies Used

- Python
- FastAPI
- Tesseract OCR
- Gemini AI
- HTML
- CSS
- JavaScript
